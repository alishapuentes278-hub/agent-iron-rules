# 工作流运行报告协议

Agent 在执行工作流时，必须在每次状态变更时向用户报告。

## 报告格式

```
[代理人中文名] 步骤编号 | 当前阶段 | 进度 | 说明
```

## 报告时机

| 时机 | 报告内容 |
|------|---------|
| 工作流启动 | Squad名 + 当前阶段 + 预期步骤数 |
| 阶段切换 | 上一阶段结果 + 下一阶段开始 |
| 子任务完成 | 具体产出物 + 文件路径 |
| 遇到阻塞 | 阻塞原因 + 需要的决策 |
| Gate 检查结果 | 通过/不通过 + 后续动作 |
| 工作流结束 | 最终交付物 + 改动清单 |

## 思考过程可见

当需要做决策时，Agent 应展示思考过程:
```
[代理人名] 思考: 
  选项A: ... 取舍: ...
  选项B: ... 取舍: ...
  选择: 选项X，因为...
```

## 进度播报铁律

- 每 30 秒至少播报一次
- 播报内容不可重复（不说同样的进度词）
- 遇到阻塞立即播报，不等定时器
- 任务完成后播报总结（改动文件 + 有意未动 + 需跟进）
